# Level 2: Fleet-Specific Composition Bigeye Prototype

This level tests whether fleet-specific composition data provide the first
meaningful separability among fleet observation processes.

Level 1B added fleet-specific catchability, but both q parameters loaded into
the same weak fixed-effect direction. Separate q values duplicated the
observation-scale problem rather than resolving it.

## Model change

Compared with Level 1B:

- keep one shared biological population
- keep fleet-specific q
- add synthetic fleet-specific age-composition patterns
- keep one shared selectivity curve for this first composition experiment

## Scientific hypothesis

Fleet-specific composition data should provide information about how fleets
sample the population. If the composition signal is informative, fixed-effect
geometry should show reduced q/R0/F confounding or a clearer separation between
observation scale and selectivity-related parameters.
