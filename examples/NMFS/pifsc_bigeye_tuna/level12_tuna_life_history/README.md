# Level 12: Tuna Life History

Level 11 showed that fixing M and longline q stabilized abundance scale, but
recruitment deviations returned to a persistent pattern. Inspection then showed
that the bigeye examples were still using inherited reef-fish/red-snapper-like
life-history schedules.

Level 12 keeps:

- fixed M = 0.18
- fixed longline q = 0.00005

and replaces the inherited weight-at-age and maturity-at-age schedules with
provisional bigeye-tuna-like diagnostic schedules.

These are diagnostic placeholders, not authoritative assessment inputs.
