# Level 14: M Sensitivity

Level 13 showed that estimated initial numbers mostly corrected excessive
age-10+ biomass. Level 14 keeps the Level 13 model but lets fixed M be supplied
at runtime via `BIGEYE_FIXED_M`.

The sweep script runs M = 0.18, 0.25, 0.35, 0.45 and compares recruitment and
plus-group diagnostics.
