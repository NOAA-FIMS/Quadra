# Fleet Package

Composes fleet dynamics for one fleet.

## State

- `FleetState`

## Parameters

- `FleetParameters`

## Steps

- `LogisticSelectivity`
- `FishingMortality`
- `BaranovCatch`

## Produces

- selectivity-at-age
- fishing mortality-at-age
- total mortality-at-age
- catch numbers-at-age
- catch biomass
