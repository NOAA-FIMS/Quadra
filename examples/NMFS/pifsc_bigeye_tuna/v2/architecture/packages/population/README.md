# Population Package

Composes population dynamics for one population.

## State

- `PopulationState`

## Parameters

- `PopulationParameters`

## Steps

- `FixedRecruitment`
- `Survival`
- `Aging`
- `PlusGroup`
- `SpawningBiomass`

## Produces

- recruits by year
- survivors-at-age
- numbers-at-age
- spawning biomass by year
